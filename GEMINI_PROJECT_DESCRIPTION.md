
# iStreamCapture Project Description

iStreamCapture is a privacy-focused, single-file web application designed for capturing ideas using voice-to-text transcription. It operates entirely on the client-side, storing all data in the browser's local storage to ensure user privacy. The application is built as a Progressive Web App (PWA), allowing it to be installed on devices for an app-like experience with offline capabilities.

## Key Features:

- **Voice-to-idea capture:** Transcribes spoken ideas into text.
- **Idea management:** Allows users to create, edit, delete, and search their ideas.
- **Privacy-first:** No user accounts are required, and all data remains on the user's device.
- **Password protection:** Secures access to the application using a locally stored, hashed password.
- **Offline functionality:** Works without an internet connection after the initial load.
- **PWA support:** Can be "installed" on desktops and mobile devices for easy access.
- **Data export/import:** Users can back up and restore their ideas in JSON format.
- **Analytics dashboard:** Provides insights into idea creation and usage patterns, with all data remaining local.

The project also includes a comprehensive test suite to ensure the reliability of its features.
